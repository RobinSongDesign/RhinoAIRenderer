# 安装与开始使用

Chameleon 是 Rhino 的 AI 渲染插件：截取当前视口，用文字描述想要的效果，生成写实的渲染图，并可以继续修改。

## 系统要求

- Rhino 8（Windows 或 macOS）
- 能访问互联网（插件需要连接 `api.rhchameleon.top`，连不上请看 [无法连接网络](/docs/network)）
- 一个 Chameleon 账号，账号里有余额（见 [账号、充值与余额](/docs/account)）

## 安装

> 插件目前处于测试阶段，测试版以 zip 压缩包提供。正式版发布后可以在 Rhino 的「包管理器」（命令 `PackageManager`）中搜索 Chameleon 安装，届时本页会更新。

1. 如果装过旧版 AIRenderer：在 Rhino 中运行 `PluginManager`，找到 AIRenderer，取消勾选或卸载，然后**完全退出 Rhino**。新版与旧版不能同时加载。
2. 把 zip 解压到一个固定的文件夹，例如 `文档\Chameleon\`。之后不要移动或删除这个文件夹，Rhino 每次都从这里加载插件。
3. 打开 Rhino 8，把文件夹中的 `Chameleon.rhp` 拖进 Rhino 窗口。
4. 运行命令 `Chameleon`，打开插件面板。（旧命令 `AIRender` 也可以。）

更新测试版时，先完全退出 Rhino，再用新 zip 中的文件覆盖原来的文件夹。

## 登录

1. 在面板的「服务商」中选择 **Chameleon 账号**。
2. 点 **登录账号**，输入在网站注册的用户名（或邮箱）和密码；开启了两步验证的账号，还需要输入验证码。
3. 登录后，服务商下方会显示账号名和余额。

密码只用于这一次登录，插件不会保存。插件会在你的账号下自动创建一个名为「Chameleon for Rhino (电脑名)」的专用令牌，用账号余额生成。详见 [账号、充值与余额](/docs/account)。

## 生成第一张图

1. 在 Rhino 中调整好视角。
2. 在面板中点 **捕获当前视图**。
3. 选择模型和图片尺寸（1K 最快也最便宜，适合先试效果）。
4. 在「提示词」里写下想要的效果，例如「黄昏，暖色灯光，写实建筑摄影」。
5. 点 **生成图片**。通常 30 到 60 秒出图，4K 会更久。

生成的每一张图都会留在左侧的历史面板里，可以对比、继续修改或保存。

## 常见问题

**面板一直显示「加载中」或空白**：关闭面板后重新运行 `Chameleon`；仍不行请重启 Rhino。

**提示「Rhino 无法连接网络」**：见 [无法连接网络](/docs/network)。

**提示余额不足**：在网站的钱包页充值或兑换，见 [账号、充值与余额](/docs/account)。
