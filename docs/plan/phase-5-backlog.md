# P5 待排期事项

这里的条目没有排期，也没有拆成可执行任务。决定要做某一项时，先按其他阶段文档的格式把它写成任务（目标、涉及文件、实现要点、验收标准），再派发。

## 运营与商业化

| 条目 | 说明 | 前置 |
|---|---|---|
| 在线支付 | 用户自助购买点数。国内走微信支付或支付宝（需要相应主体资质），海外走 Stripe。服务端新增订单表、支付回调、对账；账本新增 `purchase` 流水类型 | P4；合规确认 |
| 套餐与订阅 | 按月赠送点数、不同等级的并发上限与可用模型 | 在线支付 |
| 团队账号 | 一个团队共享点数池，成员管理，按成员统计用量 | P4 |
| 邀请与赠送 | 邀请码、新用户赠送点数、活动兑换码（一码多用，每人限一次） | P4 |
| 微信登录 | 网页登录页增加微信扫码；插件端不需要改动 | P4-T03 |
| 用量看板 | 用户侧：近 30 天的生成数与点数消耗；管理侧：留存、付费转化 | P4-T07 |

## 编辑能力

| 条目 | 说明 | 前置 |
|---|---|---|
| 多通道输入 | 同时截取着色图、线稿、深度图（`ZBufferCapture`）、材质 ID 图，作为附加输入提高几何保真度；需要先评估各模型对多通道输入的实际效果 | P3 |
| 按图层或材质生成蒙版 | 对象蒙版的扩展：按图层、按材质一键选区 | P3-T07 |
| 材质库联动 | 读取 Rhino 材质名称与贴图，自动写入提示词或作为材质参考图 | P3-T09 |
| 视频与漫游 | 命名视图序列生成一致的多帧；依赖支持视频的模型 | P3-T11 |
| 文生图与纯参考生成 | 不依赖视口截图，从文字或参考图起稿 | P3 |
| 结果回贴到模型 | 把生成图作为 Picture 对象或贴图放回 Rhino 场景 | P3-T12 |
| 另存为时复制项目 | 文档另存为新文件时复制一份编辑历史，避免两个文件共享同一项目 | P3-T02 |
