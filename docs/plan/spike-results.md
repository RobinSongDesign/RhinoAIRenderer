# 阶段 0 实测结果

原始报告与图片在 [`spike-results/`](spike-results/)。本文汇总结论，供 P0-T3 更新决策记录使用。

## Windows（已完成）

环境：Windows 11（内部版本 26200），Rhino 8.34.26223，.NET 8，插件 `net7.0` 版本，WebView2（Edge 157），缩放 125%。共运行四次（`win-rhino8.34-run1`–`run4`）；第 2、3 次用于排查 G1，第 4 次使用修正后的验证插件。

| 检查 | 结论 | 说明 |
|---|---|---|
| A1–A7 回环 HTTP | 通过 | 页面加载约 50–360 ms；RPC 往返约 3 ms；SSE、4K 图片、20 MB 上传、错误令牌返回 404 均正常 |
| B1、B2 Eto 消息通道 | 失败（不影响） | B3、B4 通过，说明 `window.eto.postMessage` 本身可用。B1 疑为页面在消息对象注入前发送；B2 是验证插件的写法问题（Eto 的 `ExecuteScriptAsync` 需要 `return`）。备用传输不需要实现 |
| C1、C2、C4 截图 | 通过 | 4K 截图约 270 ms；从后台线程经 UI 线程调用无死锁 |
| C3 命名视图 | 未测 | 测试模型没有命名视图；该逻辑沿用旧版 |
| D1–D6 输入与交互 | 通过 | 英文、中文输入法、快捷键、拖放、文件选择、Esc/空格/回车不会被 Rhino 截获 |
| E1 DPAPI | 通过 | |
| F1 系统对话框 | 通过 | 三种对话框都能弹出并返回路径（验证插件的保存对话框只返回路径、不写文件，因此打开对话框里看不到它是正常的） |
| F2 打开浏览器 | 通过 | |
| G1 物体蒙版 | 通过（修正后） | 见下文 |
| H1–H4 | 通过 | 剪贴板写图片可用；`devicePixelRatio` 1.25 |

### G1 的发现

1. 最初的蒙版只绘制物体的渲染网格，线框类显示模式下没有渲染网格，结果全黑。改为直接绘制物体几何（Brep、挤出体、网格、SubD、图块）后，着色与渲染模式下轮廓正确。曲线、点、标注没有面积，不参与蒙版；只选中曲线时蒙版为空，P3-T07 的界面要提示「请选择实体或曲面」。
2. 截图会带上选中高亮与操作轴（gumball）。验证插件和正式插件的截图都已改为截图期间临时取消选择、截完恢复（选择状态不进入撤销记录）。正式插件的这一改动尚待在 Rhino 中确认（P2-T09 人工验收时一并检查）。
3. 蒙版边缘有抗锯齿灰度（约 3% 像素既非纯黑也非纯白），P3-T07 取回蒙版后在前端做阈值处理。
4. 遮挡关系（被其他物体挡住的部分应为黑）尚未专门测试。
