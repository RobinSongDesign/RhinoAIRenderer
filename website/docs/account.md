# 账号、充值与余额

插件按张计费，费用从你的 Chameleon 账号余额中扣除。账号、充值和用量都在网站 <https://api.rhchameleon.top> 上管理。

## 注册与登录

- 在 [注册页](https://api.rhchameleon.top/sign-up) 创建账号。
- 在插件中选择「Chameleon 账号」，点 **登录账号**，输入用户名（或邮箱）和密码。
- 用微信等方式注册的账号，需要先在网站的个人设置里设置一个密码，才能在插件里登录。
- 忘记密码：在登录框点「忘记密码」，或打开 [找回密码页](https://api.rhchameleon.top/forgot-password)。

> 网站限制同一网络在 20 分钟内最多尝试登录 20 次。看到「登录尝试次数过多」时，请等 20 分钟再试，期间不要反复点击登录。

## 充值与兑换

在插件里点余额旁边的 **充值**，或直接打开网站的 [钱包页](https://api.rhchameleon.top/wallet)。

- **兑换码**：在钱包页的兑换码输入框中粘贴兑换码，点「兑换额度」，额度立即到账。
- 兑换码的购买渠道见网站公告。

## 余额与价格

- 登录后，插件在服务商下方显示账号余额；每次生成成功后自动刷新，也可以点 ↻ 手动刷新。
- 价格按模型和图片尺寸（1K / 2K / 4K）区分，见 [价格页](https://api.rhchameleon.top/pricing)。
- 生成失败（包括内容审核未通过、超时）不扣费。
- 余额不足时，插件会提示「点数或余额不足，请兑换或充值」。

## 退出与多台电脑

- 在插件中点账号名旁的 **退出**，只会删除这台电脑上保存的令牌，网站上的令牌保留，下次登录时继续使用。
- 每台电脑登录时会各自创建一个令牌。要彻底停用某台电脑，在网站的 [令牌管理](https://api.rhchameleon.top/keys) 中删除它的「Chameleon for Rhino (电脑名)」令牌。

## 手动填写令牌（可选）

不方便用账号密码登录时（例如账号只支持扫码登录），可以在网站 [令牌管理](https://api.rhchameleon.top/keys) 中新建令牌并复制，在插件的 设置 → Chameleon 账号 → API 密钥 中粘贴保存。
